# My Inventory (no database)

All data lives in `inventory_data.py`. Photos live in `images/`.

Run:    pip install -r requirements.txt && streamlit run app.py
Deploy: push this folder to GitHub -> share.streamlit.io -> main file `app.py`

To update: edit inventory_data.py (colors, sizes, new receipts), commit, and the app redeploys.
Photos: save as images/<product code>.jpg (code is the 13-digit number under each item).
